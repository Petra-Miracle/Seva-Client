# SevaAI Frontend

Next.js (App Router) + TypeScript + Tailwind CSS.

## Setup

1. `npm install`
2. Salin `.env.example` ke `.env.local`, isi `NEXT_PUBLIC_API_URL` (URL backend).
3. `npm run dev` (port 3000)
4. Build: `npm run build`

## Halaman

/, /chat, /inbox, /tickets, /campaigns, /knowledge, /dashboard
